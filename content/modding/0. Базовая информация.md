# Дамп данных
В запущенном клиенте Lethe можно нажать кнопу 0, что сделает дамп данных в папку `BepInEx\plugins\Lethe`.  
Игра может подвиснуть во время этого.
# Перезагрузка
Если же нажать кнопку 8, то игра перезагрузится без нужды перезапуска.  
Это не сработает, если были добавлены:
- Плагины/.dll файлы
- Изображения CG и Profile
- Звуки
- Баффы в `custom_buffs`
- Ключевые слова в `custom_unit_keywords`
# Рекомендации по использованию VSCode
1. Придётся работать с большим количеством .json файлов. Скрытие ненужных блоков должно облегчить работу.
2. Настройка VSCode "Форматирование при сохранении" ("Format on Save") приводит файл к определённому формату. Это создаёт постоянствоо и читаемость файлов.
# Структура файлов
`Lethe`:
- `dumpedData` - содержит неизменяемые данные, полученные напрямую из игры. Ванильные данные оттуда можно использовать в качестве шаблонов.
- `mod` - содержит все моды.
- `ModTemplate` - эта папка даёт представление о содержимом мода. Можно копировать в `mods` и изменять.
# Нахождение вещей
Моддинг можно разделить на два этапа:
1. Найти нужные неизменённые данные и скопировать их.
2. Вставить данные в нужную папку и начать с ними работать.

Первый этап всегда проходит в двух конкретных папках.
- `limbus_data` - содержит *все* неизменные данные Лимбуса (такие как характеристики идентичности, навыки, аномалии, сражения (encounters) и так далее).
- `limbus_locale` - содержит все локализационные файлы.  

Их можно найти в `Lethe\dumpedData`.
