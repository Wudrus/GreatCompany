Пассивные способности указываются в `custom_limbus_data\passive` в .json файле.

Использование существующих пассивных способностей
```json
{
  "list": [
    {
      "personalityID": 10122, //ID идентичности.
      "battlePassiveList": [ //Пассивки на поле боя.
        {
          "level": 2, //Тир, на котором способность разблокируется (ПРЕДПОЛОЖИТЕЛЬНО).
          "passiveIDList": [ //ID способностей.
            1060701
          ]
        }
      ],
      "supporterPassiveList": [ //Поддержка в запасе.
        {
          "level": 3,
          "passiveIDList": [
            1060721
          ]
        }
      ]
    }
  ]
}
```

Для создания своих модульных скриптов для пассивных способностей можно обратиться к [Этому сайту](https://rentry.co/glitchscript)
```json
{
  "list": [
    {
      "id": customidhere,
      "attributeStockCondition": [ //Требуемые ЭГО ресурсы. attributeResonanceCondition для резонанса.
      {
          "type": "AMBER", //Гнев
          "value": 2 //Количество.
        }
      ],
      "requireIDList": [
          "Each/Modular/script/goes/in/one/string",
          "Multiple/Modular/scripts/can/be/put/in/one/passive/like/so"
      ]
    }
  ]
}
```
