`limbus_data\skill\`

Один из навыков.
```json
{
    "list": [
        {
            "id": 1125001, //ID навыка. Не следует никакому паттерну. Но, думаю, было бы неплохо создавать ID навыков, используя ID идентичности. Не то, чтобы кому-то пришло в голову использовать один навык для нескольких идентичностей.
            "skillTier": 1, //Ранг навыка 1-3.
            "skillData": [
                {
                    "skillTargetType": "FRONT", //Тип наведения. FRONT - обычное поведение, наводится на выбранный слот. RANDOM - случайно, используется для союзных NPC.
                    "canTeamKill": false, //Можно ли навести на союзника.
                    "canDuel": true, //Можно ли вступить в столкновение (клеш) с этим навыком. С помощью этого можно сделать клэшабельный Блок и Контр. На Увороте не имеет эффекта.
                    "canChangeTarget": true, //Может ли изменить цель. В основном, используется для навыков противников по понятным причинам.
                    "attributeType": "SHAMROCK", //Грех навыка.
                    "atkType": "SLASH", //Тип атаки. SLASH/PENETRATE/HIT - Режущий/Пронзающий/Дробящий.
                    "defType": "ATTACK", //Нужно для защитных навыков. ATTACK/GUARD/EVADE/COUNTER - Атака/Защита/Уворот/Контр. Для Контра нужен atkType.
                    "skillMotion": "S1", //Анимация навыка. У обычных навыков что-то по типу "S1","S2","S3","S5". У защитных навыков "Default".
                    "viewType": "BATTLE", //BATTLE - обычный. ENCOUNTER - как у 3 навыков.
                    "targetNum": 1, //Вес атаки/Количество целей.
                    "range": 6.5, //Предположительно, нужно для анимаций. На каком расстоянии персонаж становится напротив противника.
                    "defaultValue": 8, //Базовая сила навыка.
                    "skillLevelCorrection": 1, //Определяет уровень атаки навыка. Аналогично уровню защиты идентичности. На 55 уровне идентичности этот навык будет иметь 55+1=56 уровень атаки.
                    "`mpUsage": 0, //В оригинальном навыке нет этой строки. Сколько СД будет потрачено при использовании.
                    "abilityScriptList": [ //Эффекты навыка, не связанные с монетами.
                        {
                            "scriptName": "GiveBuffOnUse",
                            "buffData": {
                                "buffKeyword": "Breath",
                                "target": "Self",
                                "stack": 1,
                                "turn": 0,
                                "activeRound": 1
                            }
                        }
                    ],
                    "coinList": [ //Монеты. Каждый элемент - одна монета. В этом навыке только одна монета.
                        {
                            "operatorType": "ADD", //Тип операции. ADD - сложение, SUB - выситание и... MUL - умножение? Вау.
                            "scale": 3, //Сила монеты.
                            "abilityScriptList": [ //Эффекты навыка, связанные с монетами.
                                {
                                    "scriptName": "GiveBuffOnSucceedAttack",
                                    "buffData": {
                                        "buffKeyword": "Breath",
                                        "target": "Self",
                                        "stack": 0,
                                        "turn": 2,
                                        "activeRound": 1
                                    }
                                }
                            ]
                        }
                    ]
                }
            ]
        }
    ]
}
```

Эффекты навыка.
```json
   {
"scriptName": "GiveBuffOnUse", //Наложение навыка при использовании навыка.
"buffData": {
    "buffKeyword": "Breath", //Накладываемый эффект.
    "buffOwner": "", //Здесь не используется. Нужен для других навыков?
    "target": "Self", //Цель, на которую будет наложен эффект. Ниже есть примеры целей.
    "stack": 1, //Сила эффекта.
    "turn": 0, //Счётчик эффекта.
    "activeRound": 1 //Когда эффект наклажывается. 0 - в текущем ходе, 1 - в следующем.
 }
}
```
Эффекты/Ключевые слова можно посмотреть [на сайте](https://soshage.com/limbus/keyword) или в `limbus_locale\bufList`.  
Примеры целей наложения навыка:
- `Self`
- `Target`
- `EveryAlly`
- `RandomEnemy1(2,3,5)`
- `EveryEnemy`

Скрипты (Эффекты) навыка можно найти [здесь](https://docs.lethelc.site/faq/Script).  

Особые монеты:
- `grade` - место монеты в иерархии. 2 - Красная монета, 3 - Зелёная монета. Влияет на **поведение** монет.
- `color` - цвет монеты. GREY - Красная монета (ПОЧЕМУ-ТО), GREEN/PURPLE - Зелёная/Фиолетовая соответственно. Влияет на **внешний вид** монеты.

Ориентировочные клеши (не очень?).  
Skill 1: 11-12  
Skill 2: 16  
Skill 3: 18
