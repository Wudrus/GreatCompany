# Как начать
1. Зайти в папку `Lethe`.
2. Открыть `dumpedData` в VSCode.
3. Открыть `limbus_data`.
4. Пролистать до папки `personalities`.
	- Там должно быть 12 .json файлов от 0 (И Сан) до 11 (Грегор) в порядке номеров грешников (Немного устарело, но в целом, всё так же).
	- Идентичности грешников в этих файлах *не названы*, но достаточно точно описаны. Также, их добавляют в порядке выхода.

5. Нужно скопировать нужный файл в `custom_limbus_data\personality` внутри папки мода.
6. Затем нужно стереть в файле все идентичности кроме одной. С ней и будет идти работа. (Не забудем убрать ненужную запятую в конце.)

Чтобы у идентичности было название, нужно в папке мода `custom_limbus_locale\EN\personalityList` создать .json файл.

Шаблон содержимого.
```json
{
	"<ID>": {
		"id": "<ID>",
		"name": "Yi Sang",
		"desc": "Yi Sang’s 1st Identity",
		"title": "LCB\nSinner",
		"acquisitionMethod": "Unknown",
		"oneLineTitle": ""
	}
}
```

\<ID> - нужно заменить id нужной идентичности.  
`name` - Имя **персонажа**. Любая идентичность И Сана будет иметь "name": "Yi Sang".  
`desc` - Не используется. Можно сказать, просто комментарий разработчика. В описании всех ванильных идентичностей просто указан их порядковый номер. Например, у Lobotomy E.G.O:: Faint Aroma & Solitude Рёшу - "Ryōshū's 14th Identity".  
`title` - Название самой идентичности.  
`acquisitionMethod` и `oneLineTitle` - По всей видимости не используются. У всех Unknown и пустота.
