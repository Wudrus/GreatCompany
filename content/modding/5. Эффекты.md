```json
{
  "list": [
    {
      "id": "NailPersonality", //Нужно создать файл .txt в custom_buffs с ID эффекта.
      "iconId": "Nail", //ID, которая должна будет находиться в названии спрайта иконки эффекта.
      "buffClass": "NonvolatileBuff", //Классы эффектов описаны ниже.
      "buffType": "Negative", //Negative/Neutral/Positive. Используется для взаимодействия с этим эффектом. Например, убрать один случайный негативный эффект.
      "canBeDespelled": true, //Можно ли насильно убрать.
      "list": [], //Что эффект делает
      "categoryKeywordList": ["LACERATION"] //Нужен для создания вариаций других эффектов. Например, у Dark Flame - COMBASTION (Огонь).
    }
  ]
}
```
Классы эффектов:
- `NonvolatileBuff` - есть только сила. Не истекает.
- `VolatileBuff` - есть только сила. Истекает.
- `CountableBuff` - есть сила и счётчик.
- `sinBuff` - есть сила и счётчик. Используется для архетипов основных 7 статусов.

Дополнительные параметры:
- `maxStack` - лимит силы. По умолчанию: 99.
- `maxTurn` - лимит счётчика. По умолчанию: 99.
- `attributeType` - предназначение неизвестно. Базовые статусы соотносятся со своими грехами.
- `destroyableOnZero` - убирается ли с 0 силы.
- `destroyableOnZeroTurn` - убирается ли с 0 счётчика.
- `destroyableOnRetreat` - убирается ли отступлении.

Скопировать без комментариев.
```json
{
  "list": [
    {
      "id": "NailPersonality",
      "iconId": "Nail",

      "buffType": "Negative",
      "canBeDespelled": true,
      "list": [],
      "categoryKeywordList": ["LACERATION"]
    }
  ]
}
```
