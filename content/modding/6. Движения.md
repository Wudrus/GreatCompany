# 2. Экспорт движения
Для экспорта нужно нажать ПКМ в пуcтом месте `assets` и нажать `Build AssetBundles`. Файл будет в `Assets/AssetBundles`.
Добавление в мод:
```
MyMotion / --- Папка мода
    custom_motions /
        10101_YiSang_BaseAppearance / --- Название движения
            motion.bundle --- Тот самый файл
```

# 3. Анимация Idle
1. Выбрать объект.
2. Двойной ЛКМ по его таймлайну.
3. Там три ряда: Один для размера, один для позиции, один для самих спрайтов.
4. Раскрыть ряд для спрайтов.
5. Выбрать нужные спрайты и перетянуть в ряд для спрайтов.
6. Можно настроить скорость, выбрав кадры и растянув их.
7. Сохранить анимацию на Ctrl+S
# 4. Анимация атаки
Для работы анимаций атак нужны .json файлы в папку с motions.bundle в моде.
```json
{
  "$schema": "https://raw.githubusercontent.com/LEAGUE-OF-NINE/motions-schema/refs/heads/main/schema.json", //Нужен для подсказок VSCode.
  "coins": [ //Количество монет, которые состовляют движение.
    {
      "totalDuration": 0.0, //Длительность монеты.
      "phases": [], //Действия внутри монеты.
      "hitCheckers": [] //Отметка, когда монета кончается. Обычно, одна на монету.
    }
  ]
}
```

Пример фазы 1

```json
{
  "type": "ToTargetWide", //Тип фазы. Эта двигает персонажа к цели.
  "start": 0.0, //Когда происходит действие.
  "end": 0.1, //Когда происходит действие.
  "steps": 1, //Количество повторений
  "move": { "x": 1, "y": 0, "z": 0 }, //Положение относительно цели. x=1, чтобы избежать перекрытие.
  "isRefreshDir": false //Обновить ли направление персонажа. (Не тестилось)
}
```

Пример фазы 2

```json
{
  "type": "GiveDamage", //Наносит урон цели.
  "start": 0.15,
  "end": 0.15, //Урон наносится в конце движения.
  "steps": 1,
  "sturn": { //Настройка отбрасывания.
    "sturnType": "KNOCKBACK", //Тип отбрасывания.
    "forcePower": 5, //Сила отбрасывания.
    "randomPower": 0, //Случайная вариация силы.
    "sturnTiming": "ALL" //Когда цель отбрасывается.
  }
}
```

HitChecker

```json
"hitCheckers": [{ "time": 0.15 }] //Монета заканчивается в это время.
```

Мульти-атаки (атаки с несколькими монетами) требуют отдельные таймлайны.

Название таймлайна должно содержать название навыка и номер монеты.  
Например, S2_1 - навык S2, вторая монета (отсчёт с нуля).  
Нужно перетащить новый таймлан в `Hierarchy` и связать его с `Appearence`, перетянув его с того окна внутрь настройки таймлайна. Также нужно связать его с motion.bundle в окне `Assets Labels` внизу справа.  
Можно сделать длину монеты дольше анимации. Тогда перед следующей монетой будет пауза.
